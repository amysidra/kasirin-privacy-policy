# Privacy Policy - Kasirin Aja

Terakhir diperbarui: 30 April 2026

## Pengumpulan Data
Kasirin Aja tidak mengumpulkan, menyimpan, atau mengirimkan data pribadi pengguna ke server manapun. Semua data transaksi dan pembukuan tersimpan sepenuhnya di perangkat pengguna (lokal).

## Data yang Disimpan
Seluruh data (transaksi, catatan pembukuan) hanya tersimpan di penyimpanan lokal perangkat Android pengguna dan tidak dapat diakses oleh pihak manapun selain pengguna itu sendiri.

## Keamanan Data
Karena tidak ada data yang dikirim ke server eksternal, risiko kebocoran data dari sisi aplikasi tidak ada.
